HOW TO USE THIS PACK
====================
1. Create your project folder and copy everything in this zip into it
   (AGENTS.md at the project root, the docs/ folder beside it).
2. Open the folder in Antigravity.
3. If Antigravity has a "rules" setting, paste the contents of AGENTS.md there too.
4. Open docs/KICKOFF.md and paste its prompt as your FIRST message.
5. Review the agent's summary and plan, then approve.
6. For each phase, paste the "Phase prompt" from KICKOFF.md (swap the phase number).
7. Test each phase yourself in the browser before moving on.

Files
-----
AGENTS.md          Standing rules the agent must follow every session
docs/KICKOFF.md    The first-session prompt and the per-phase prompt
docs/SPEC.md       Overview, tech stack, data model, UI layout, global requirements
docs/phase-1.md .. phase-8.md   One file per build stage
docs/TASKS.md      Checklist the agent ticks off as it goes
